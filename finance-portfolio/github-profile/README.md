### What I've been building

| Project | What it answers |
| :--- | :--- |
| **[equity-valuation-dcf](TODO-link)** | What is a company worth — and what growth rate does its market price already assume? A reverse DCF answers the second question, which is the one that decides anything. |

rather than behind a library call. 95 unit tests across the five.

### How I work

- **State the question before the answer.** Every write-up opens with what it is trying to
  find out, and closes with what it concluded and what would prove it wrong.
- **Report the results that do not help.** The covariance shrinkage that did nothing. The
  diversification that did not pay. The peer set that collapses to one company. A portfolio
  where nothing ever fails is a portfolio that is not measuring anything.
- **Say where the data came from.** The sample data in these projects is generated rather
  than real, it says so on every front page, and each project documents exactly how to point
  the same pipeline at real filings or real prices.
